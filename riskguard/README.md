# RiskGuard - Cyber Security Landing Page

A single-page responsive website built with HTML5, CSS3, and Bootstrap 5.

## Structure
```
riskguard/
├── index.html      # Main page
├── css/
│   └── style.css   # Custom styles
├── js/
│   └── script.js   # Back-to-top + nav behavior
└── README.md
```

## Run it
Just open `index.html` in a browser, or use a Live Server in VS Code (see chat instructions).
No build step or installs required — Bootstrap is loaded via CDN.
